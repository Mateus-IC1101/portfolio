APLICATIVO EDUK ALUNO

Desenvolvimento de um aplicativo integrado ao sistema acadêmico das faculdades, proporcionando aos alunos funcionalidades essenciais para o dia a dia estudantil.


O aplicativo foi desenvolvido em Flutter. Fui, também, responsável pela implementação do backend (API REST) em Laravel e pela integração das notificações push via Firebase Cloud Messaging (FCM), utilizando processamento com filas e agendamento por cronjob, garantindo alta performance e escalabilidade no envio das notificações.


Financeiro do aluno (geração de boletos bancários, 2ª via de boleto)

Consulta de notas e desempenho acadêmico

Atualização de informações pessoais

Compartilhamento de arquivos

Armazenamento local de documentos

Integração e manipulação de dados via API REST/p>

Persistência local de dados

Integração com Firebase Cloud Messaging (FCM) para envio e recebimento de notificações

Disponível na Play Store e   Apple Store
